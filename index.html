MONTE AS INSTRUÇÕES / SEM DIGITAR

O robô começa na casa 0. A estrela está na casa 3.

    O que aprendemos com isso?

    Um algoritmo é uma sequência de instruções para realizar uma tarefa. “Pegar” antes de chegar à estrela muda o resultado. A ordem faz parte da solução.

    3 MIN / CONVERSA + PRÁTICA

    Guardar, decidir e repetir.

    Essas ideias aparecem em jogos, sites e aplicativos. Vamos entendê-las com o mesmo robô.

    1 / VARIÁVEL

    Uma informação que pode mudar.

    O nome é passos. O valor agora é 2.

    2 / CONDIÇÃO

    Uma pergunta decide o caminho.

    Tem pelo menos 3 passos?

    Ainda não.

    O robô precisa de mais um passo para chegar.

    3 / REPETIÇÃO

    A mesma ação, várias vezes.

    Cada bloco representa uma execução de “andar”. Repetimos a ação pelo número escolhido.

    4 / FUNÇÃO

    Dar um nome a uma tarefa para usá-la novamente.

    darEnergia() pode reunir os passos de aumentar o valor, respeitar um limite e atualizar o robô. Vamos abrir essa regra no laboratório.

    Pergunte antes de mover o controle: com 2 passos dá para chegar? E com 3? O que se repete e o que decide?
