# Fontes e escopo

A oficina tem como foco **tecnologia para alunos do ensino médio**, com HTML, CSS, JavaScript, cibersegurança e quatro grupos de carreira: Desenvolvimento de software, Analista de Suporte/Infraestrutura, Analista de Dados e Cibersegurança.

O projeto acadêmico de base é “Fábrica de Software na Prática: Desenvolvimento Web, Cibersegurança e Carreiras em TI”, do Grupo 04, Ciência da Computação, UNINASSAU, Campus Graças. A apresentação foi reorganizada conforme a orientação do grupo: os assuntos se conectam por processos visuais e exemplos cotidianos.

O laboratório concentra os trechos de código. As outras telas mostram resultados, camadas, regras e responsabilidades. Front-end, back-end e full stack são apresentados dentro de Desenvolvimento de software.

## Exemplos e limites

- A página “Meu primeiro site” é um exemplo introdutório. O botão muda uma mensagem no navegador, sem inscrição, cadastro ou envio de dados.
- As trocas entre navegador, servidor e banco são um modelo simplificado, sem backend real.
- Visitante e Editor autorizado ilustram uma regra de permissão local. Em sistemas reais, a autorização deve ser verificada no servidor.
- A verificação de dispositivo, rede e serviço é uma simulação. Nenhuma conexão real do usuário é testada.
- O gráfico contém **60 escolhas fictícias**: Jogos 24, Vídeos 20 e Música 16. Não é uma pesquisa com os alunos nem uma estatística de mercado.
- Mensagens e pedidos de autenticação são fictícios e servem para discutir cuidados cotidianos.
- A segunda etapa de autenticação mostrada na área de carreira é ilustrativa. O botão não muda configurações de uma conta real.
- O trecho de cibersegurança usa fundamentos e permanece editável para o grupo definir seu recorte. O caso externo da versão anterior não faz parte desta sequência.
- Funções profissionais podem se sobrepor entre empresas. O material não apresenta pesquisa salarial ou garantia de emprego.

As atividades não coletam dados pessoais dos alunos. Respostas e marcações ficam na sessão do navegador e são apagadas ao recarregar.
